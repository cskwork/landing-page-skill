Feature Cards

Auto-fitting grid with icon, title, and description. Hover reveals gradient top border.

Fast & Lightweight

Zero dependencies, instant load. No frameworks, no build step, just plain HTML.

<div class="feature-grid">
  <div class="feature-card reveal">
    <div class="feature-icon">
      <svg viewBox="0 0 24 24" ...><path d="..."/></svg>
    </div>
    <h3>Feature Title</h3>
    <p>Description with <code>inline code</code>.</p>
  </div>
  <!-- repeat for more cards -->
</div>

Code Blocks

Terminal-style code display with copy button. Add .kw, .str, .cmt spans for syntax highlighting.

bash 
npm install your-package
<div class="code-block">
  <div class="code-header">
    <span class="code-dots"><i></i><i></i><i></i></span>
    <span class="code-lang">bash</span>
    <button class="code-copy">Copy</button>
  </div>
  <pre><code>npm install your-package</code></pre>
</div>

Tooltips

Pure CSS tooltips. No JavaScript needed. Use .tooltip-wide for multi-line.

Hover over: this text

Wide variant: hover me 

<!-- Basic tooltip -->
<span class="tooltip-trigger" data-tooltip="Helpful text">
  Hover me
</span>

<!-- Wide (multi-line) tooltip -->
<span class="tooltip-trigger tooltip-wide" data-tooltip="Longer explanation...">
  Hover me
</span>

Tabs

Tabbed content panels. Add data-tabs to the container.

Content for tab 1.

Content for tab 2.

<div data-tabs>
  <div class="tab-list">
    <button class="tab-btn active" data-tab="t1">Tab 1</button>
    <button class="tab-btn" data-tab="t2">Tab 2</button>
  </div>
  <div class="tab-panel active" data-panel="t1">
    <p>Content for tab 1.</p>
  </div>
  <div class="tab-panel" data-panel="t2">
    <p>Content for tab 2.</p>
  </div>
</div>

Scroll Reveal

Add .reveal class to any element. It fades + slides up when scrolled into view. Requires app-template.js.

<div class="feature-card reveal">
  <!-- Content hidden until scrolled into view -->
</div>

Internationalization (i18n)

Add data-i18n="key" to elements, define window.translations, and include language buttons.

<!-- HTML -->
<p data-i18n="hero.title">Welcome</p>
<button class="lang-btn active" data-lang="en">EN</button>
<button class="lang-btn" data-lang="ko">한국어</button>

<!-- JavaScript -->
<script>
window.translations = {
  en: { "hero.title": "Welcome" },
  ko: { "hero.title": "환영합니다" }
};
</script>
<script src="app-template.js"></script>
