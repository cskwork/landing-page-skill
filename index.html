Why This?

Everything You Need

A production-ready design system that ships as two files. No npm install, no webpack, no config.

Zero Dependencies

Two files — design-system.css and app-template.js. No npm, no build tools. Just copy and go.

Dark & Light Themes

CSS variables make theme switching instant. One attribute on <html> flips the entire palette.

Scroll Animations

Add .reveal to any element. IntersectionObserver handles smooth fade-up as users scroll. Progressive enhancement.

Pure CSS Tooltips

Helpful tooltips with data-tooltip — no JavaScript needed. Wide variant for multi-line text.

Responsive by Default

Every component adapts from mobile to desktop. CSS Grid and clamp() handle fluid sizing automatically.

Agent Skill Ready

Ships as a skill — AI agents can build pages from it. Follows writing-great-skills best practices.

Get Started

Quick Start

From zero to a beautiful landing page in 3 steps.

1

Copy the Files

Grab the design system — just two files:

bash 
git clone https://github.com/cskwork/landing-page-skill.git
cp -r landing-page-skill/design-system/ your-project/
2

Link & Build

Add to your HTML and start composing sections:

html 
<link rel="stylesheet" href="design-system.css">
<script src="app-template.js"></script>

<section class="hero">
  <h1 class="hero-title">
    <span class="gradient-text">Hello</span>
  </h1>
</section>
3

Customize Tokens

Edit :root variables to match your brand:

css 
:root {
  --accent-cyan: #your-color;
  --accent-purple: #your-color;
  --gradient-primary: linear-gradient(
    135deg, #your1, #your2
  );
}

Deployment

Deploy to GitHub Pages

Free hosting in under a minute. This very page is on GitHub Pages.

bash 
# 1. Create a public repo
gh repo create my-landing-page --public

# 2. Add your files and push
git add . && git commit -m "Add landing page"
git push origin main

# 3. Enable GitHub Pages
#    Settings → Pages → Source: Deploy from branch
#    Branch: main → / (root) or /docs

# 4. Your site is live at:
#    https://<username>.github.io/my-landing-page/
